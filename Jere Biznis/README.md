# Glory2YahPub Institution Management — Complete Standalone Module

Runnable Flask/PWA implementation of the requested blueprint:
- institution management foundation
- Primary Owner and Backup Admin roles
- 30-day free trial
- reminder at every connection/login
- 500 Gkach/month
- 1, 3, 6, 12 or custom multi-month prepayment
- subscription extension
- idempotent payment records
- audit trail
- offline IndexedDB queue
- sync push/pull endpoints
- encrypted backup primitives
- tenant isolation
- billing dashboard

The real Glory2YahPub source repository was not attached, so this package is a complete
standalone module rather than a claim that the existing application has been modified.
Connect app/services/gkach.py to the real Gkach wallet/transaction service before production.

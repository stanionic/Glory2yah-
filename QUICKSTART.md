# 🚀 QUICK START GUIDE

## Start the Application

### Windows
Double-click: `START.bat`

OR

```bash
python run.py
```

### Linux/Mac
```bash
python3 run.py
```

---

## Access URLs

- **Home**: http://localhost:8080
- **Marketplace**: http://localhost:8080/mache
- **Cart**: http://localhost:8080/cart
- **Wallet**: http://localhost:8080/gkach/wallet
- **Login**: http://localhost:8080/auth/login

---

## Bottom Navigation

- 🏠 **Akèy** (Home) - Social feed with stories
- 🛒 **Mache** (Marketplace) - Product grid
- ➕ **Kreye** (Create) - Create new post
- 🛍️ **Panyen** (Cart) - Shopping cart with badge
- 👤 **Pwofil** (Profile) - User profile & Gkach wallet

---

## Key Features

### Home Feed
- Stories (horizontal scroll)
- Social posts (infinite scroll)
- Like, comment, share
- Video autoplay

### Marketplace
- 2-column grid (mobile)
- Category filters
- Sort by price/popularity
- Quick add to cart

### Shopping Cart
- Add/remove items
- Quantity controls
- Real-time totals
- Visual checkout

### Gkach Wallet
- Balance display
- Earnings dashboard
- Referral link
- Transaction history

## Troubleshooting

### App won't start?
```bash
python test_startup.py
```

### Database issues?
```bash
del instance\glory2yahpub.db
python run.py
```

### Dependencies missing?
```bash
pip install -r requirements.txt
```
